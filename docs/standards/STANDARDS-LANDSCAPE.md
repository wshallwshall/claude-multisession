# This page moved

**"The standards landscape" was one page doing two jobs, and it has been split.** It carried a
routing table for working out which documents were worth your attention, and a forty-row reference
table that was a verbatim second copy of the reference page's rows. Two copies of one status is the
failure both pages are about, so the rows now live in one place.

- **Which of these is even worth your attention** --
  [Which security standards actually apply to you](WHICH-STANDARDS-APPLY.md). The routing table and,
  on the served site, the interactive selector.
- **One row per document, and the reasoning behind the cuts** --
  [Security standards reference](STANDARDS-REFERENCE.md). What each one issues, what triggers it,
  the status with the date it was checked, and a check you can run yourself.

This file exists only so that links to the old URL still land somewhere useful, and it is not listed
in [the download table](OVERVIEW.md#the-files). A Word copy is generated beside it for the same
reason the page is: somebody has the old download URL, and a pointer is worth more to them than a
404.
