A link from somewhere else was probably written against the old address. This documentation moved
on 2026-08-10, and the paths changed with the host: pages that sat under `/claude-multisession/`
now sit at the root, so `.../claude-multisession/CONCEPTS.html` is [CONCEPTS.html](CONCEPTS.md)
here.

- [Start at the front page](index.md), which carries the quickstart and the full inventory of what
  ships.
- [Concepts](CONCEPTS.md) is the right entry point if you are trying to work out what this project
  does rather than looking for one particular page.

## Why this page exists at all, which is not obvious

Without it, this site answers **every** unknown address with the home page and a `200`, Cloudflare
Pages' default for a project with no `404.html`. A reader gets a plausible page, not an error; a
check asking "does this URL work" gets a `200` that means nothing.

**A broken link and a working one become indistinguishable from both ends.** That is the failure
this project's documents are about, **so the site hosting them should not ship it.**

Measured on 2026-08-10 against the sibling site that moved first: with no `404.html`, a nonexistent
address returned `200` and bytes identical to the home page. With one, it returns a real `404`. The
old GitHub Pages host returned a real 404 on its own, so the move introduced this regression.
