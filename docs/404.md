If you followed a link from somewhere else, it was probably written against the old address. This
documentation moved on 2026-08-10, and the paths changed as well as the host: pages used to sit
under `/claude-multisession/`, and they now sit at the root. So
`.../claude-multisession/CONCEPTS.html` is now [CONCEPTS.html](CONCEPTS.md) here.

- [Start at the front page](index.md), which carries the quickstart and the full inventory of what
  ships.
- [Concepts](CONCEPTS.md) is the right entry point if you are trying to work out what this project
  does rather than looking for one particular page.

## Why this page exists at all, which is not obvious

It is here because without it, this site answers **every** unknown address with the home page and an
HTTP 200. That is Cloudflare Pages' default for a project with no `404.html`. The reader gets a
plausible page rather than an error, and a check asking "does this URL work" gets a `200` that means
nothing. A broken link and a working one become indistinguishable from both ends. That is the
failure this project's documents are about, so the site hosting them should not ship it.

Measured on 2026-08-10 against the sibling site that made this move first: with no `404.html`, an
address that cannot exist returned `200` and bytes identical to the home page. With one, it returns
a real `404`. The GitHub Pages host this site moved off returned a real 404 without being asked,
so this is a regression the move introduced rather than something inherited.
