Every heading already carries an id, generated by kramdown, so the links existed and nothing offered them. WHY NOT JAVASCRIPT. assets/style.css states the rule: a feature may run a script only when the answer it presents is complete before any script runs, and "if a future feature cannot say that second sentence about itself, it does not get a script either." A script-built table of contents cannot say it -- without the script there is no list at all. So it is built here, at build time, and is complete in the served HTML. WHY NOT `{:toc}`. kramdown's marker would have to be added to each markdown file, and these sources are read directly on GitHub as well as built here -- the marker is kramdown's, not a construction the other surface has any reason to honour. A layout costs the markdown nothing. The stronger form of this argument left with the standards: their pages were also converted to Word, where the marker came out as a stray list item.
